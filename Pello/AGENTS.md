# Project instructions for agents

## Canonical Pello V1 product objective

Before every task that plans, changes, reviews, tests, documents, or makes architectural decisions about Pello in this project, read `PELLO_V1_PRODUCT_SPEC.md` in full. Treat it as the canonical statement of the intended final product and use it as a continuing reference throughout the work. Revisit the relevant sections whenever making a decision or reporting status; do not rely on memory or on older summaries in place of the document.

The specification describes the target, not proof of current implementation. Keep target requirements distinct from verified, mock-only, partial, and unimplemented capabilities. When useful, cite the applicable section or acceptance ID. If implementation evidence conflicts with the target, report the gap rather than silently changing the target. Follow higher-priority instructions and the user's current explicit direction if they change scope.
